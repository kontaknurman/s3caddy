Tambah domain

Satu bucket boleh punya banyak domain, tapi satu domain hanya menunjuk ke satu bucket. Panel menulis {{.SitesDir}}/<domain>.caddy yang mem-proxy ke {{.WebTarget}} sambil mengganti header Host menjadi nama bucket, lalu menjalankan systemctl reload caddy. Kalau reload gagal, file dikembalikan seperti semula dan pesan error Caddy ditampilkan di sini.

Pastikan DNS domain sudah mengarah ke server ini sebelum menambah, supaya Caddy bisa menerbitkan sertifikat TLS otomatis.
