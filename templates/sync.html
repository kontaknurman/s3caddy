Tambah remote

Ubuntu dan Debian bawaannya menolak login root dengan password (PermitRootLogin prohibit-password). Kalau Tes koneksi bilang "unable to authenticate", pakai kunci SSH.

Host key server (opsional)

Kosongkan: panel mengambil host key dari server sekarang dan menampilkan sidik jarinya untuk dicocokkan. Setelah itu setiap koneksi diverifikasi, jadi server palsu tidak bisa menyadap password.

Password/kunci disimpan di remotes.json (0600), hanya diberikan ke rclone lewat environment proses, dan tidak pernah ditampilkan lagi. Job berjalan dengan hak user SSH ini; folder sistem (/etc, /usr, /root, .ssh, …) ditolak.

Region harus cocok dengan endpoint, kalau tidak tanda tangan ditolak. Setelah disimpan, jalankan Tes koneksi dengan nama bucket: panel membaca bucket, menulis lalu menghapus satu objek uji, dan mengganti gaya alamat otomatis kalau provider hanya menerima salah satu.

Impor / ekspor bucket

Salin isi satu bucket (atau satu folder di dalamnya) dari remote ke Garage atau sebaliknya. Objek di tujuan tidak pernah dihapus.

{{if not .Remotes}}
Tambah remote dulu di atas; setelah itu form job muncul di sini.
{{else}}
Sumber · remote

Isi folder (beserta subfoldernya) disalin; folder sistem ditolak. Di ekspor, folder dibuat kalau belum ada.

→
Tujuan · Garage

Tiap transfer memakai ±16 MiB buffer. Naikkan pelan-pelan; kalau provider melempar SlowDown/429, turunkan lagi.

Job jalan di server, checkpoint tiap {{.ChunkKeys}} objek. Tab boleh ditutup; setelah restart panel job lanjut sendiri. Kedua sisi diperiksa dulu (termasuk uji tulis di tujuan) sebelum transfer dimulai.
…atau jalankan berulang sesuai jadwal

Tulis 30m, 6h, atau 2d (minimal 15 menit, maksimal 30 hari). Tanpa run pertama, run pertama = sekarang + interval. Tiap run membuat job dengan setelan di atas; kalau bucket atau folder-nya masih dipakai job lain, run itu dilewati. Run yang terlewat saat panel mati tidak dirapel.
